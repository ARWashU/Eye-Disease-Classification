# 🧠 Biomedical Signal Classification using CNN

> Deep Learning Meets Biomedical Engineering 🧬

This project leverages **Convolutional Neural Networks (CNNs)** to classify biomedical signals from EEG and ECG datasets. Our goal was to explore how deep learning can effectively distinguish patterns in noisy physiological data, providing a foundation for diagnostic tools and health tech innovation.

- **EEG (Electroencephalogram)**

> Note: Due to sensitivity and privacy, data source details may be excluded from public versions.

## 🧠 Model Overview

- ✅ CNN architecture tailored for 1D signal inputs  
- 🏗️ Layers: Conv1D → MaxPooling → Dense → Softmax  
- 📉 Evaluated with training vs. validation accuracy plots  
- 🎯 Achieves high classification accuracy for binary/multiclass signal types
